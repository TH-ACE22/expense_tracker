# 💰 Expense Tracker (Full Stack App)

A full-stack **Expense Tracker** application that helps users manage, categorize, and visualize their daily spending.  
Built using **Flask (Python)** for the backend REST API, **PostgreSQL** for data persistence, and **React + Vite** for the frontend UI.

---

## 🚀 Tech Stack

### 🧠 Backend
- **Python 3.10+**
- **Flask** – Lightweight web framework
- **Flask SQLAlchemy** – ORM for database management
- **Flask JWT Extended** – JSON Web Token authentication
- **Flask CORS** – Enable secure communication between backend and frontend
- **PostgreSQL** – Relational database for persistent data storage

### 🎨 Frontend
- **React + Vite** – Fast, modern web development
- **Axios** – For making API requests
- **React Router** – Navigation between pages
- **TailwindCSS / CSS Modules** – (optional) styling

---

## 🧩 Features

✅ User registration & login (JWT-based authentication)  
✅ Create, view, edit, and delete expenses  
✅ Categorize expenses (Food, Travel, Bills, etc.)  
✅ PostgreSQL-powered backend database  
✅ RESTful API design for easy frontend integration  
✅ Secure password hashing with Werkzeug  
✅ Cross-Origin access enabled for React frontend
